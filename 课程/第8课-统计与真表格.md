## 16-3 · SQL（思路：GROUP BY 是分组计数，JOIN 是外键拼表）

```sql
USE fzix;

-- 1) 按城市统计院校数（/api/stats 的 SQL 原型）
SELECT city, COUNT(*) AS cnt
FROM school
GROUP BY city
ORDER BY cnt DESC;

-- 2) 学校+专业合并表（外键连回来的样子）
SELECT s.name AS 学校, m.major AS 专业
FROM school s
JOIN majors m ON m.school_id = s.id;
```

| 语句 | 意思 |
|---|---|
| `GROUP BY city` | 按 city 分组，每组算一个 COUNT(*) |
| `AS cnt` / `AS 学校` | 给列起别名，结果表头更好看 |
| `JOIN majors m ON m.school_id = s.id` | 两表按外键等值拼接，s/m 是表的短别名 |

**验证**：GROUP BY 结果厦门=2、福州=1（接着 14-8 的样例数据算）；JOIN 出 3 行学校+专业对。Workbench 结果网格右上角导出图标 → 存 CSV → 截图。

## 16-4 · 思路

把 15-3 的写死数组换成 fetch 读本地文件——其余一行不用改，这就是分层的好处。data.json 从 MySQL 导出（Workbench 导出 CSV 后另存改后缀，或手写一份）。

```html
<!-- m4.html，与 data.json 放同一文件夹 -->
<table border="1">
  <thead><tr><th>学校</th><th>城市</th></tr></thead>
  <tbody id="tb">加载中…</tbody>
</table>

<script>
  fetch("data.json")
    .then(function (r) { return r.json(); })
    .then(function (list) {
      const tbody = document.querySelector("#tb");
      tbody.innerHTML = list.map(function (s) {
        return `<tr><td>${s.name}</td><td>${s.city}</td></tr>`;
      }).join("");
    });
</script>
```

```json
// data.json —— 列表里装对象，和 Python 的 list[dict] 一模一样
[
  { "name": "厦门大学", "city": "厦门" },
  { "name": "闽江学院", "city": "福州" },
  { "name": "集美大学", "city": "厦门" }
]
```

| 代码 | 意思 |
|---|---|
| `.map(fn)` | 数组每项加工一遍返回新数组——对应 Python 列表推导式 `[f(x) for x in list]` |
| `.join("")` | 数组拼成一个整字符串 |
| 本地双击打开 fetch 可能被浏览器拦 | 右键用 Live Server 打开（或 VSCode Go Live），本地文件协议有跨域限制 |
