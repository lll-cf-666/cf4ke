## 15-1 · 思路

真实站点会超时、403、断网。把"发请求"封成一个函数——失败自动重试 3 次、每次歇 2 秒，全失败返回 None 让调用方跳过。抓学校官网再加 User-Agent 头，把"我是浏览器"写在请求头上过最基本的脚本拦截。

```python
# crawler15.py —— 带三件套的抓取骨架
import requests, time, csv
from bs4 import BeautifulSoup

HEADERS = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/120 Safari/537.36"}

def get(url, tries=3):
    for i in range(tries):                 # 最多试 3 次
        try:
            r = requests.get(url, timeout=15, headers=HEADERS)
            if r.status_code == 200:
                return r                   # 成功：直接把响应交回去
            print("状态码", r.status_code, "第", i + 1, "次")
        except Exception as e:
            print("出错", e, "第", i + 1, "次")
        time.sleep(2)                      # 失败歇 2 秒再试
    return None                            # 3 次全败：放弃这个 URL

# 用法：r = get("https://zs.xmu.edu.cn")
# if r is None: print("跳过这所学校")
```

| 代码 | 意思 |
|---|---|
| `def get(url, tries=3)` | 默认参数：调用时不写 tries 就用 3——和每日任务 D06 同一个知识点 |
| `return r` / `return None` | 函数把结果交回调用处；None 是"没有结果"的标准信号 |
| `headers=HEADERS` | 请求头里带上浏览器身份，403 的第一味药 |

## 15-2 · 思路

重复行、空行都是脏数据。用 set 记"见过的名字"，第二次见到就跳过——这是去重保序的标准套路（和每日任务 D04"去重保序"完全同源）。

```python
# clean15.py —— raw.csv → clean.csv
import csv

rows = list(csv.reader(open("raw.csv", encoding="utf-8-sig")))
head, body = rows[0], rows[1:]           # 第一行是表头，剩下的才是数据

seen = set()
clean = []
for r in body:
    name = (r[1] or "").strip()          # r[1] 是校名列——按你自己的列顺序改下标
    if name and name not in seen:        # 非空 且 没见过
        seen.add(name)
        clean.append(r)

with open("clean.csv", "w", newline="", encoding="utf-8-sig") as f:
    w = csv.writer(f)
    w.writerow(head)
    w.writerows(clean)

print("原始", len(body), "行 → 清洗后", len(clean), "行")
```

**验证**：两数对比合理（脏行被剔）；clean.csv 打开无空行无重复。
