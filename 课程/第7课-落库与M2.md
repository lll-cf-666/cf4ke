## 16-1 · 思路

Python 操作 MySQL 四步——connect 建连接 → cursor 拿"执行器" → execute 跑 SQL → fetchone/fetchall 拿结果。密码填你装 MySQL 时自己设的 root 密码。

```python
# db.py —— Python ↔ MySQL
import pymysql

conn = pymysql.connect(
    host="127.0.0.1",          # 数据库在哪：本机
    user="root",               # 账号
    password="你的MySQL密码",   # 装库时自己设的
    database="fzix",           # 14-8 建的库
    charset="utf8mb4"
)
cur = conn.cursor()
cur.execute("SELECT COUNT(*) FROM school")
print("school 表行数:", cur.fetchone()[0])
conn.close()
```

| 代码 | 意思 |
|---|---|
| `pymysql.connect(...)` | 建立到数据库的连接，之后的操作都走这条通道 |
| `conn.cursor()` | 执行器：所有 SQL 从它发出去 |
| `cur.fetchone()` | 取一条结果（COUNT 查询只有一行） |
| `conn.close()` | 用完关连接，资源要还 |

**验证**：装包 `pip install pymysql`，跑通打印真实行数。

## 16-2 · 思路

不再落 CSV——爬到一条 INSERT 一条。防重复靠两道保险：school.name 上的 UNIQUE 约束 + INSERT IGNORE（撞了 UNIQUE 就静默跳过）。重跑一遍行数不变 = M2 达标。

```python
# m2_write.py —— 爬取结果直写 MySQL
import requests, pymysql
from bs4 import BeautifulSoup
from crawler15 import get          # 15-1 的三件套函数直接复用

conn = pymysql.connect(host="127.0.0.1", user="root",
                       password="你的MySQL密码", database="fzix",
                       charset="utf8mb4")
cur = conn.cursor()

sql = "INSERT IGNORE INTO school (name, city, type, url) VALUES (%s, %s, %s, %s)"

# 示例数据（M1 实际抓出来的字段往这循环里喂）
DATA = [
    ("厦门大学", "厦门", "本科", "https://zs.xmu.edu.cn"),
    ("闽江学院", "福州", "本科", "https://zsb.mju.edu.cn"),
    ("厦门大学", "厦门", "本科", "https://zs.xmu.edu.cn"),   # 故意重复，测 IGNORE
]

for name, city, typ, url in DATA:
    cur.execute(sql, (name, city, typ, url))    # %s 占位由 pymysql 安全填入
    conn.commit()                               # 写操作必须 commit 才真正落库

cur.execute("SELECT COUNT(*) FROM school")
print("行数:", cur.fetchone()[0])               # 重复那条没进去 = 成功
conn.close()
```

| 代码 | 意思 |
|---|---|
| `INSERT IGNORE` | 撞上 UNIQUE 约束的行直接跳过，程序不报错 |
| `cur.execute(sql, (参数元组))` | 参数化写法：值不经拼接直接入库，防 SQL 注入也防引号炸 |
| `conn.commit()` | MySQL 默认"试运行"，commit 才落账——忘了 commit 数据全没 |
